# The Collective Designs — Commission Website

This is the redesigned, non-store Collective Designs site.

## Put it in GitHub / Codespaces
Upload these files into the root of your site:

- `index.html`
- `styles.css`
- `script.js`

The decorative avatar is an inline SVG, so there are no image dependencies for the main character.

## What was removed
- Flappy Bat/Moth
- word-search/game system
- prize wheel/rewards
- shop/cart/checkout language
- product-store focus

## Main sections
- Home
- About Me
- Random Facts
- My Vibe
- What I Can Make
- Portfolio
- Prices
- Packages
- Fees & Policies
- Why Work With Me
- Contact / Commission enquiry

## Contact email

## Editing
All copy and prices are plain HTML. Search `index.html` for the heading you want to edit.
